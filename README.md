# Дневник тренировок

Персональное мобильное PWA. Приложение позволяет составлять программы,
быстро фиксировать подходы, продолжать тренировку без сети, просматривать
историю, динамику веса и объёма, массу тела и кардио.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес, который появится в терминале. В локальной среде приложение
использует демонстрационный профиль и демонстрационные данные.

## Проверки

```bash
pnpm test
pnpm lint
```

Тесты покрывают расчёт объёма и рекордов, правило трёх последовательных недель,
идемпотентность офлайн-очереди и обязательные PWA-настройки.

## Хранение и доступ

- основное серверное хранилище — Cloudflare D1;
- локальный кэш и очередь несинхронизированных изменений — IndexedDB;
- идентификация пользователя выполняется сервером через защищённые заголовки
  среды размещения;
- каждый вошедший пользователь читает и изменяет только своё состояние;
- при локальном запуске данные изолированы хранилищем конкретного браузера.

Миграции находятся в папке `drizzle` и применяются средой размещения.

## Установка на iPhone

1. Откройте опубликованный адрес в Safari.
2. Нажмите кнопку «Поделиться».
3. Выберите «На экран “Домой”».
4. Подтвердите название и нажмите «Добавить».

PWA откроется в отдельном окне. После первого успешного запуска интерфейс и
активная тренировка доступны без сети.

## Развёртывание

Проект подготовлен для OpenAI Sites. Конфигурация размещения находится в
`.openai/hosting.json`, база данных подключается логическим именем `DB`.
Секреты в репозитории не используются.

## Ограничения первой версии

- вход выполняется через защищённую учётную запись среды размещения, а не через
  отдельную форму email/пароль;
- конфликт изменений одной записи разрешается последней подтверждённой версией;
- фотографии прогресса, push-уведомления и таймер отдыха оставлены для
  следующих этапов согласно спецификации.
